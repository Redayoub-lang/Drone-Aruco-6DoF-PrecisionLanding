# Autonomous Drone GPS-Denied 6-DoF Precision Landing Estimator

![Python 3](https://img.shields.io/badge/Language-Python%203.10-blue)
![OpenCV](https://img.shields.io/badge/Library-OpenCV%20ArUco-green)
![Developer](https://img.shields.io/badge/Developer-Ayoub%20Lahmar-brightgreen)

A deterministic spatial computer vision pipeline for autonomous UAV precision landing in GPS-denied environments. Implements **Perspective-n-Point (PnP)** iterative solving over square fiducial targets to compute full relative \(6\text{-DoF}\) transformation matrices (\(t_x, t_y, t_z, \theta_{yaw}, \theta_{pitch}, \theta_{roll}\)).

Developed by **Ayoub Lahmar** ([@Redayoub-lang](https://github.com/Redayoub-lang)) for application to **Jiangsu University (JSU)**.
